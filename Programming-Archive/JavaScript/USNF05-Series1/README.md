# USNF05 - JavaScript Programming - Series 1

My solutions for Series 1 of the USNF05 JavaScript Programming course (ISSAE).

This series is about the basics:
- reading user input with `prompt()`
- displaying results with `alert()`
- conditions (`if` / `else if` / `else`)
- explicit conversions (`Number()`, `parseInt()`, `isNaN()`)
- a first simple `while` loop

Each exercise is a small standalone HTML page. Just open it in a browser
and it will run (it uses prompt / alert dialogs).

The original exercise sheets (Series 1, Part 2, and the official solution
PDF) are kept in this folder for reference.
