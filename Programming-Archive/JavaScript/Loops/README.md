# JavaScript - Loops Practice

My solutions for the "Loops" exercise sheet (while, do...while and a few for loops).

- Exercises 1 to 4: basic while loops (printing, counting, summing)
- Exercises 5 to 8: loops with user interaction (prompt) and do...while
- Exercises 9 to 11: bonus series questions with for loops
  (factorial, sum of powers 1^1 + 2^2 + ... + n^n, exponential series)

The console-based exercises print their result in the browser console
(open it with F12). The interactive ones use prompt() / alert() dialogs.

The original exercise sheet (Exercise 2 - Loops.docx) is kept in this folder.
